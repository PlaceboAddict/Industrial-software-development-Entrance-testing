## Обзор решения 
* _Kotlin language_
* _O(n) time_ 
* _O(1) space_ — используется входной массив


### Формат входных данных
На вход принимается файл [input.txt](src/input.txt) из директории `./src/`,
каждая `i`-я строка которого представляет список элементов
`triangle[i]`, разделенных запятой.

Разделитель и название файла могут быть изменены в функции `main`.


### Алгоритм решения
Берется исходный экземпляр входного треугольника.

Проход начинается с предпоследней строки (последняя остается без изменений).
Для каждого `i`-го элемента минимальный путь до него снизу вверх: 
минимум из `i`-го и `(i + 1)`-го элемента предыдущей строки.
Таким образом, вычисляется наименьшая стоимость маршрута 
от вершины треугольника до его основания.

Опционально можно отрисовать треугольник с помощью функции `drawTriangle()`.
